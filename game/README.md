# 动物叠叠乐 · Animal Stack

一款无需构建、无外部依赖的单人层叠三消小游戏，玩法类似「羊了个羊」：

- 点击没有被上层遮挡的小动物。
- 小动物会进入底部 7 格“动物小窝”。
- 三只相同图案的小动物会自动消除。
- 小窝被填满且没有触发三消，则本局失败。
- 默认 2 关，一局约 5–10 分钟。

## 运行

直接双击 `index.html`，或在项目根目录运行：

```bash
python3 -m http.server 8000
```

访问 <http://localhost:8000/game/>。

## 操作与道具

- 点击最上层、没有被遮挡的小动物。
- 「撤销」会把最后一只仍在窝里的小动物放回棋盘；小窝满时也可撤销一次继续。
- 「洗牌」会重新排列剩余小动物的图案，但不会改变每种图案的总数量。
- 「提示」会高亮一组当前可点击的同图案小动物。
- `P` / `Esc` 暂停。

第一关“熊猫竹林”共 72 只小动物，第二关“晚霞牧场”共 111 只。每关通过后点击「继续闯关」。

## 默认动物图案

游戏内置 12 种图案，全部使用本地 Emoji，不依赖网络资源：

`🐼 熊猫`、`🐰 兔子`、`🦊 狐狸`、`🐨 考拉`、`🐱 猫咪`、`🐶 小狗`、`🐻 小熊`、`🐯 老虎`、`🐸 青蛙`、`🐧 企鹅`、`🦉 猫头鹰`、`🐥 小鸡`。

## 增加关卡

关卡位于 `js/levels.js` 的 `RAW_LEVELS` 数组。向数组追加配置即可，不需要修改游戏引擎：

```js
{
  id: "new-meadow",              // 唯一 ID
  name: "晨光草地",
  subtitle: "新的动物层叠关卡说明",
  columns: 7,                    // 4–10，推荐 7
  rows: 7,                       // 4–10，推荐 7
  layerCounts: [27, 24, 18, 15], // 从底层到顶层；总数需为 3 的倍数
  kindCount: 9,                  // 使用默认动物库中的前 9 种
  traySize: 7,                   // 5–10
  seed: 3108,                    // 棋盘随机种子
  tools: { undo: 2, shuffle: 2, hint: 3 },
  theme: {
    backgroundStart: "#fff7e8",
    backgroundEnd: "#d9f3e8",
    accent: "#ed7658",
    accent2: "#5dbd9c",
    danger: "#e85d72",
    text: "#49382f",
    board: "#d8efdf",
    tileTop: "#fffdf7",
    tileBottom: "#f2ddbd",
    tileEdge: "#cbb087"
  }
}
```

也可以使用 `tileCount` 和 `layers` 自动分配每层数量：

```js
{
  id: "auto-layers",
  tileCount: 90,
  layers: 4,
  // 其他字段同上
}
```

### 自定义动物图案

为关卡添加 `kinds` 数组即可覆盖默认动物库：

```js
kinds: [
  { id: "alpaca", glyph: "🦙", color: "#b88d68", label: "羊驼" },
  { id: "monkey", glyph: "🐵", color: "#9a6c43", label: "猴子" },
  { id: "hedgehog", glyph: "🦔", color: "#816449", label: "刺猬" }
]
```

至少需要 3 种。每种图案在棋盘中的总数会自动按 3 的倍数分配。

## 配置健壮性

启动时会自动校验并规范化关卡：

- 非对象关卡和重复 `id` 会被跳过。
- 行列、层数、小窝容量和道具数量会被限制在安全范围。
- 层数容量不足时自动裁剪。
- 小动物总数会自动调整为 3 的倍数。
- 少于 3 种有效图案时回退到默认动物库。
- 棋盘生成器会保证存在一条可行解法，避免生成无解初始牌面。
- 无有效关卡时加载内置应急关卡，页面不会白屏。
- 配置提示会输出到浏览器控制台，并可在游戏内显示。

## 架构与 UI 替换

- `levels.js`：动物图案、关卡、主题配置，以及配置校验。
- `board.js`：纯棋盘生成、遮挡判定、提示、洗牌和可解性验证。
- `game.js`：游戏状态、动物小窝、三消、计分、道具和关卡推进，不直接操作 DOM。
- `ui.js`：DOM 棋盘、动物小窝和覆盖层渲染，监听游戏事件。
- `styles.css`：奶油色动物主题、响应式布局和全部动效。
- `index.html`：页面结构与可替换文案。

因此可以单独替换 `ui.js`、`styles.css` 或 `index.html`，而不改动关卡与核心规则。
